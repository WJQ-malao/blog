花了两天时间，我从零搭建了自己的个人博客 [wjqblog.cn](https://wjqblog.cn)，包括买域名、部署、手写主题。总成本 **38 元**（域名两年），其余全部免费。这篇文章记录完整过程和踩过的坑，给想搭博客的朋友一份能照着走的路线图。

<!-- more -->

## 最终成果

- **地址**：https://wjqblog.cn
- **技术栈**：Hexo（静态生成）+ GitHub（存代码）+ Cloudflare Workers（免费托管）+ 自定义域名
- **特色**：手写紫色科技风主题、打字机欢迎页、中英文切换、RSS 订阅

写作流程非常爽：本地写 Markdown → `git push` → 一分钟后网站自动更新。

## 第一步：本地搭起 Hexo

装好 Node.js 和 Git 之后，三条命令起家：

```bash
npx hexo-cli init blog
cd blog
npx hexo s        # 浏览器打开 localhost:4000 预览
```

在 `_config.yml` 里把语言改成 `zh-CN`、时区改成 `Asia/Shanghai`，再 `git init` 推送到 GitHub，本地部分就完成了。

## 第二步：部署，然后踩坑

我选了 Cloudflare Workers 做托管（免费、Git 推送自动构建）。配置很简单：构建命令 `npm run build`，仓库里加一个 `wrangler.jsonc` 告诉它静态文件在 `public/` 目录：

```json
{
  "name": "blog",
  "compatibility_date": "2025-10-01",
  "assets": { "directory": "./public" }
}
```

部署很顺利，但问题来了——**Cloudflare 的免费域名 `workers.dev` 在国内根本打不开**（DNS 污染）。

于是转战腾讯云 EdgeOne Pages，国内秒开，高兴了一晚上。第二天再访问，**401 了**。查官方文档才发现：EdgeOne"含中国大陆"区域的免费域名是**预览性质，链接 3 小时过期**。

结论有点扎心但很重要：**免费平台 + 免费域名的组合，在国内无法长期公开访问。** 想认真写博客，一个自己的域名是绕不开的。

## 第三步：买域名，一了百了

在腾讯云买了 `wjqblog.cn`，**两年 38 元**，一杯奶茶钱。这里纠正一个常见误解：买域名 ≠ 买服务器。静态博客托管在免费平台上，永远不需要服务器，要花钱的只有域名。

接入 Cloudflare 也就三步：

1. Cloudflare 添加域名，拿到两个名称服务器地址（`xxx.ns.cloudflare.com`）
2. 回腾讯云把域名的 DNS 服务器换成这两个（**两个都要换，一主一备**）
3. 等几分钟生效后，在 Workers 项目的 Domains 里绑定域名

HTTPS 证书 Cloudflare 自动签发，不用碰任何密钥和证书文件。绑定完成，`https://wjqblog.cn` 国内直接可访问。

## 第四步：手写一个主题

没用任何第三方主题，整站样式自己写，成就感拉满：

- **主页**：深紫渐变背景 + 打字机效果（"欢迎来到我的Blog"逐字打出，光标闪烁，打完简介淡入）
- **博客页**：玻璃拟态文章卡片，悬停上浮发光
- **小功能**：中英文切换（localStorage 记忆选择）、文章页点空白返回列表、RSS 订阅引导页（一键复制订阅地址）

主题文件在 `themes/purple/`，主页是手写的 `source/index.html`（通过 `skip_render` 跳过 Hexo 渲染）。RSS 用 `hexo-generator-feed` 插件，构建时自动生成 `atom.xml`。

## 经验总结

1. **免费域名在国内都不靠谱**：workers.dev 被墙、EdgeOne 限时 3 小时。便宜域名（约 20 元/年）是最小成本。
2. **域名安全 = 账号安全**：没有密钥要管，保护好腾讯云和 Cloudflare 的账号密码就行。
3. **`url:` 配置不决定能否访问**，它只管 RSS、sitemap 里的链接写什么——但记得改成正式域名。
4. **一切皆代码**：主题、页面、配置全在 Git 仓库里，改坏了 `git revert` 一键回滚，换电脑 `git clone` 完整复活。
