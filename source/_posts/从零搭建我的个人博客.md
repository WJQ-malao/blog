## 最终架构

```
本地写 Markdown → git push → GitHub 仓库
        ↓（自动触发）
Cloudflare 拉取代码、构建 → 部署上线
```

以后每次写完文章，只需 `git push`，一分钟后网站自动更新。

## 第一步：准备环境

1. 安装 **Node.js**（LTS 版）和 **Git**，官网下载一路默认安装
2. 注册 **GitHub** 账号和 **Cloudflare** 账号（可用 GitHub 登录）

## 第二步：本地搭建 Hexo

```bash
npx hexo-cli init blog     # 初始化项目
cd blog
npx hexo s                 # 本地预览 http://localhost:4000
```

在 `_config.yml` 里把语言改成 `zh-CN`、时区改成 `Asia/Shanghai`。

写文章用 `npx hexo new "标题"`，会在 `source/_posts/` 生成 Markdown 文件。

## 第三步：推送到 GitHub

在 GitHub 新建一个空仓库（不勾选 README），然后：

```bash
git init -b main
git add .
git commit -m "init hexo blog"
git remote add origin https://github.com/你的用户名/blog.git
git push -u origin main
```

## 第四步：部署到 Cloudflare Workers

1. Cloudflare → **Workers & Pages** → **Create application**，关联 GitHub 仓库

![Workers & Pages 创建应用](/img/blog-setup/step4-1-create-app.png)

2. 选择 **Continue with GitHub**，授权后选中你的博客仓库

![关联 GitHub 仓库](/img/blog-setup/step4-2-connect-github.png)

3. 构建配置：
   - Build command：`npm run build`（Hexo 自带 `"build": "hexo generate"`）
   - Deploy command：`npx wrangler deploy`
4. 仓库里添加 `wrangler.jsonc`，声明静态文件目录：

```json
{
  "name": "blog",
  "compatibility_date": "2025-10-01",
  "assets": { "directory": "./public" }
}
```

push 之后 Cloudflare 自动构建部署，博客就上线了。

## 第五步：踩坑——免费域名国内无法访问

部署很顺利，但访问时问题来了：

- **Cloudflare** 的免费域名 `*.workers.dev`：国内被 DNS 污染，直接打不开
- 改用**腾讯云 EdgeOne Pages**：国内能开，但它的免费域名只有 **3 小时预览有效期**，过期返回 401

结论：**免费平台 + 免费域名的组合在国内无法长期使用**，想让博客稳定公开访问，必须有自己的域名。

## 第六步：买域名并绑定（关键一步）

注意：买域名 ≠ 买服务器，静态博客托管在免费平台上，永远不需要服务器。

### 6.1 腾讯云购买域名

1. 打开腾讯云**域名注册**控制台，在搜索框输入想要的名字（如 `wjqblog`），逐个后缀查看是否可注册

![腾讯云域名注册控制台](/img/blog-setup/step6-1-1-domain-console.png)

2. 选好后缀（`.cn` 两年 38 元；`.com` 更通用但贵一些），点击立即购买
3. **信息模板**：首次购买需要创建，填真实姓名、身份证、邮箱（就是域名实名认证，审核几分钟）
4. **"搭配购买"的产品全部不勾**——都用不上
5. 支付后等实名审核通过，在"我的域名"里看到状态为"正常"即可

![购买完成后的域名列表](/img/blog-setup/step6-1-2-my-domain.png)

### 6.2 接入 Cloudflare

1. Cloudflare → **Domains** → **Add domain** → **Connect a domain**（不要选 Transfer/Buy）

![Cloudflare 添加域名](/img/blog-setup/step6-2-1-add-domain.png)

2. 输入域名（只填 `wjqblog.cn`，不要加 `http://` 或 `www`），其余选项保持默认，点 Continue

![输入域名](/img/blog-setup/step6-2-2-connect-domain.png)

3. DNS 记录页面**什么都不用加**，直接点 **Continue to activation**，弹窗选 **Confirm**
4. 激活页面会给出**两个 Cloudflare 名称服务器**（形如 `xxx.ns.cloudflare.com`），复制下来

### 6.3 腾讯云修改 DNS 服务器

1. 腾讯云 → 域名注册 → 我的域名 → 点域名 → **管理**
2. 找到 **DNS 服务器 → 修改** → 选"使用非腾讯云 DNS"

![修改 DNS 服务器](/img/blog-setup/step6-3-1-modify-dns.png)

3. 把默认的两个 dnspod 地址**替换成** Cloudflare 给的两个（**两个都要换，一主一备**）→ 提交
4. 回 Cloudflare 点 **I updated my nameservers**，等几分钟检测通过，显示 ✓ Active

> 改 DNS 服务器就是声明"这个域名归 Cloudflare 管"，这是整个接入的核心操作。

### 6.4 绑定到 Workers 项目

1. Cloudflare → **Workers & Pages** → 点已有的 blog 项目（**不要走 Create 新建流程**）

![进入已有的 blog 项目](/img/blog-setup/step6-4-1-project-domains.png)

2. 顶部 **Domains** 标签 → **Add Domain**

![添加自定义域名](/img/blog-setup/step6-4-2-add-domain.png)

3. Subdomain **留空**（即绑定主域名），Enable for 保持 **Production** → 点 **Add domain**

![绑定域名弹窗：Subdomain 留空](/img/blog-setup/step6-4-3-connect-dialog.png)

HTTPS 证书由 Cloudflare 自动签发，不需要配置任何密钥。

最后把 `_config.yml` 里的 `url:` 改成 `https://wjqblog.cn`，push 一次收尾。

## 日常使用

```bash
npx hexo new "文章标题"     # 新建文章
npx hexo s                  # 本地预览
git add . && git commit -m "新增文章" && git push   # 发布
```

## 经验总结

1. **免费域名在国内都不靠谱**：workers.dev 被墙、EdgeOne 限 3 小时，一个便宜域名（约 20 元/年）是最小成本
2. **域名安全 = 账号安全**：没有密钥要管，保护好腾讯云和 Cloudflare 的账号密码即可
3. **改 DNS 服务器是域名接入的核心操作**，作用就是声明"这个域名归 Cloudflare 管"
4. **一切配置都在 Git 仓库里**，改坏了 `git revert` 回滚，换电脑 `git clone` 复活
